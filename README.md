# АЛЬФА ПРИНТ — контакты и полиграфия в Нальчике

Адаптивная статическая страница с оригинальным логотипом, контактами и услугами компании. В основе — согласованная с владельцем версия мультиссылки. Никаких вымышленных отзывов, фотографий работ или контактов.

## Состав

- `index.html` — вся страница (HTML, CSS, JS, оригинальная аватарка и брендовые SVG встроены).
- `robots.txt`, `sitemap.xml` — основы поискового индексирования.
- `404.html` — информативная страница для неверных URL.
- `.nojekyll` — простая публикация в GitHub Pages.
- `SECURITY.md` — границы защиты и рекомендации по DDoS.

## Развёртывание

GitHub Pages в настройках репозитория должен использовать `Deploy from a branch` → `main` → `/ (root)`. Адрес после публикации: https://sultanbalkarov22-droid.github.io/alfa-site/ . Если домен/настройки отличаются, обновите canonical, og:url, robots и sitemap.

Для своего домена нужно подтвердить владение им, настроить DNS и HTTPS. Чтобы реально включить защиту от DDoS и WAF, нужно провести трафик через защищённый CDN, например Cloudflare, по инструкциям в SECURITY.md.

## SEO

Предусмотрены заголовок с «Полиграфия в Нальчике», meta-description, `lang=ru`, LocalBusiness JSON-LD, sitemap и robots. Это НЕ гарантирует попадание в топ выдачи, а также не заменяет подтверждение собственности в Яндекс Вебмастере и Google Search Console. Рекомендуется зарегистрировать сайт в Яндекс Бизнесе и обеспечить ссылки из официальных карточек компании.
