# Безопасность и рекомендации по DDoS — АЛЬФА ПРИНТ

## Проверено

- Сайт статический: нет пользовательской регистрации, cookies сессий, хранения паролей, API-ключей, базы данных или серверных форм.
- Нет внешних JS/CSS-зависимостей; логотип и иконки встроены, что уменьшает риски цепочки поставок.
- Для каждой внешней ссылки с `target="_blank"` задано `rel="noopener noreferrer"`.
- Политика Content Security Policy ограничивает скрипты точными SHA-256 хэшами, блокирует сетевые подключения JS и внешние источники. Встроенные стили разрешены для существующего дизайна. GitHub Pages не позволяет выставлять полноценные security headers из репозитория.
- Добавлен `no-referrer`, клавиатурная ссылка на основной контент и поддержка reduced motion.

## Что *не* выполнено автоматически

DDoS-защита на уровне сети НЕ устанавливается HTML-файлом и не устанавливается средствами репозитория. Для WAF / rate limiting / CDN нужен доступ к аккаунту, где управляются домен, DNS и хостинг. Не утверждайте, что Cloudflare подключён без подтверждения.

## Включение защиты после подключения домена

1. Подтвердить владение доменом и создать сайт в CDN/WAF-провайдере (например, Cloudflare); выставить DNS-записи согласно провайдеру и GitHub Pages, исключить DNS-конфликты.
2. Включить проксирование HTTP(S) записей (orange-cloud у Cloudflare), TLS/HTTPS и автоматические сертификаты; проверить HTTPS и не допускать mixed content.
3. Включить управляемые WAF-правила и DDoS mitigations, где доступны, настроить rate limiting с исключениями для поисковых роботов при необходимости. Режим Under Attack использовать только при атаке, поскольку JS-челленджи могут осложнить индексацию.
4. Проверить работоспособность Telegram, WhatsApp, карт, мобильных устройств, корректность редиректов и отсутствие циклов TLS.
5. Ограничить права на репозиторий, включить MFA для GitHub, проверки PR, мониторить Pages Actions.

## Дополнительные ограничения

CSP через `<meta>` не поддерживает `frame-ancestors` и ряд иных HTTP security headers. Для полноценных `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, `frame-ancestors` нужен контролируемый сервер/CDN. Защита от DDoS не гарантирует полной недоступности атак. Проводите внешнее тестирование только с согласия владельца.
